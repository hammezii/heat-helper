# Logger API
This is the API reference for the heat_helper logger. You can find usage examples **[here](../usage/logger.md)**.

::: heat_helper.logger.enable_logging
    options:
        heading: "hh.enable_logging"
        show_root_heading: true
        heading_level: 2
        show_source: False

::: heat_helper.logger.disable_logging
    options:
        heading: "hh.disable_logging"
        show_root_heading: true
        heading_level: 2
        show_source: False
